# Product Principles v0.1

## Authenticity

Every meaningful claim carries provenance, confidence and a life period. The system prefers direct recordings over summaries and summaries over inference.

## Temporal identity

Snapshots are immutable. Later corrections and reflections attach to the old state without replacing it. A reconstructed childhood snapshot never receives the same status as a self-recorded snapshot created during childhood.

## Consent as product state

Consent is a versioned object that gates processing. Revocation changes what the system may do, while the audit record preserves the fact that authorization once existed.

## Stewardship instead of ownership transfer

The creator controls the Legacy. A successor receives duties and bounded permissions, not ownership of the person's identity.

## Honest AI

Memory Mode stays within supported evidence. Reflection Mode may extrapolate from values and patterns but labels the answer as a reasoned possibility. Both modes respect the selected time boundary.

## Portability

Canonical data includes original media, transcripts, structured memories, relationships, timeline, provenance and consent. Embeddings, indexes and model caches remain derived infrastructure.

## Emotional safety

The system never claims loneliness, asks the user not to leave, competes with living relatives or sends manipulative notifications in a deceased person's voice.
